# 有哪些方式可以使对象的属性不能修改

在 JavaScript 中，可以通过多种方式让对象的属性**不能被修改**，常见方法如下：

---

## 1. `Object.freeze(obj)`

- **作用**：让对象**完全不可变**（属性不能被修改、添加、删除，属性值也不能被修改）。
- **用法**：
  ```javascript
  const obj = { a: 1 };
  Object.freeze(obj);
  obj.a = 2;      // 无效
  obj.b = 3;      // 无效
  delete obj.a;   // 无效
  console.log(obj.a); // 1
  ```
- **注意**：只冻结第一层属性（浅冻结），嵌套对象仍可变。

---

## 2. `Object.seal(obj)`

- **作用**：**禁止添加和删除属性**，但**可以修改已有属性的值**。
- **用法**：
  ```javascript
  const obj = { a: 1 };
  Object.seal(obj);
  obj.a = 2;      // 有效
  obj.b = 3;      // 无效
  delete obj.a;   // 无效
  console.log(obj.a); // 2
  ```

---

## 3. `Object.defineProperty(obj, prop, { writable: false })`

- **作用**：让**单个属性只读**，不能被修改。
- **用法**：
  ```javascript
  const obj = {};
  Object.defineProperty(obj, 'a', {
    value: 1,
    writable: false
  });
  obj.a = 2;      // 无效
  console.log(obj.a); // 1
  ```
- **可配合 configurable: false 禁止删除**。

---

## 4. `const` 声明对象

- **作用**：**不能修改变量的引用**，但**对象属性仍可变**。
- **用法**：
  ```javascript
  const obj = { a: 1 };
  obj.a = 2;      // 有效
  // obj = {}     // 报错：不能重新赋值
  ```
- **注意**：`const` 不能防止属性被修改，只能防止变量被重新赋值。

---

## 5. 深度冻结（递归冻结）

- **作用**：让对象及其所有嵌套属性都不可变。
- **用法**：
  ```javascript
  function deepFreeze(obj) {
    Object.freeze(obj);
    Object.keys(obj).forEach(key => {
      if (typeof obj[key] === 'object' && obj[key] !== null) {
        deepFreeze(obj[key]);
      }
    });
  }
  const obj = { a: 1, b: { c: 2 } };
  deepFreeze(obj);
  obj.b.c = 3; // 无效
  ```

---

## 6. Proxy 拦截

- **作用**：通过 Proxy 拦截属性的设置操作，实现自定义的"只读"逻辑。
- **用法**：
  ```javascript
  const obj = { a: 1 };
  const readOnlyObj = new Proxy(obj, {
    set(target, prop, value) {
      console.warn('属性不可修改');
      return true;
    }
  });
  readOnlyObj.a = 2; // 控制台警告，属性未被修改
  ```

---

## 总结对比

| 方法                        | 是否可修改属性值 | 是否可添加属性 | 是否可删除属性 | 是否递归冻结 |
|-----------------------------|------------------|----------------|----------------|--------------|
| Object.freeze               | 否               | 否             | 否             | 否（可递归） |
| Object.seal                 | 是               | 否             | 否             | 否           |
| defineProperty(writable:0)  | 否（单属性）     | -              | 可（默认）     | 否           |
| const                       | 是               | 是             | 是             | 否           |
| Proxy                       | 可自定义         | 可自定义       | 可自定义       | 可自定义     |

---

**一句话总结：**  
> 常用的让对象属性不可修改的方法有 `Object.freeze`、`Object.seal`、`Object.defineProperty`、递归冻结和 Proxy 拦截，推荐用 `Object.freeze` 或递归冻结实现只读对象。
